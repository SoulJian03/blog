Prometheus+Grafana 监控系统搭建

详细介绍基于 Ubuntu 系统的 Prometheus+Grafana 监控系统搭建方案，包括 Prometheus 服务端配置、多类型 Exporter 部署（Node、MySQL、Redis、WMI）、Grafana 可视化配置及常用故障排查，适用于企业级服务器集群与云原生环境监控。

一、Prometheus 监控框架介绍

1.1 核心概述

Prometheus 是谷歌开源的监控软件，采用 Golang 开发，通过部署在目标机器上的 Exporter 采集异构数据，统一转化为标准格式后通过 HTTP 协议传输至服务端，存储在本地时序数据库中。前端搭配 Grafana 实现数据可视化，广泛支持 Kubernetes、容器、OpenStack 等云原生环境及传统服务器、中间件监控。

1.2 Exporter 工作原理

Exporter 可理解为监控适配器，针对不同监控目标提供专属实现：

  • Node Exporter：读取 Linux /proc//sys 目录文件，获取操作系统运行状态
  • MySQL Exporter：通过读取数据库监控表采集 MySQL 性能数据
  • Redis Exporter：通过 Redis 命令行接口获取缓存服务指标
  • WMI Exporter：适配 Windows 系统，采集系统资源与服务状态

5.2 初始访问与数据源配置

  • 访问地址：http://192.168.2.45:3000
  • 初始账号密码：admin/admin（首次登录需修改密码）

添加 Prometheus 数据源

  1. 点击左侧 Configuration → Data Sources → Add data source
  2. 选择 Prometheus 类型
  3. 配置核心参数：
    • Name：Prometheus（自定义）
    • URL：http://192.168.2.45:9090
    • Scrape interval：15s
  4. 点击 Save & Test，显示 Data source is working 即为成功

5.3 导入 Dashboard 模板

5.3.1 Linux 系统监控模板（ID: 8919）

  1. 点击左侧 Create → Import
  2. 在 Import via grafana.com 输入模板 ID：8919
  3. 选择数据源为之前创建的 Prometheus
  4. 点击 Import 完成导入
  5. 查看 Dashboard：Dashboards → Manage → 1 Node Exporter for Prometheus Dashboard CN

5.3.2 MySQL 监控模板

  1. 下载模板文件：https://pan.baidu.com/s/12S33kZkZd9gIXF8tMHKECg（提取码：9b0s）
  2. 点击 Import → Upload JSON file，选择下载的 JSON 文件
  3. 选择 MySQL 数据源（需提前在 Grafana 中添加 MySQL 数据源）
  4. 完成导入

5.3.3 Redis 监控模板

  • 模板下载：https://pan.baidu.com/s/1LIkVC0o3lyTT59JbX0mSpg（提取码：gf1d）
  • 导入步骤同上，选择 Prometheus 数据源

5.3.4 Windows 监控模板（ID: 10467）

  1. 导入模板 ID：10467
  2. 选择 Prometheus 数据源
  3. 完成导入，可查看 Windows 系统 CPU、内存、磁盘等监控数据
