Yakit 使用实战：MITM 抓包、插件商店、POC 执行、手工测试与 Web Fuzzer，定位、原理、影响、利用、检测与防御。

写在前面：合法学习边界

Yakit 仅用于授权测试。对非授权目标执行 POC、扫描可能触犯法律。

一、工具定位

Yakit 是国产集成化安全测试平台，定位类似“Burp Suite + 插件商店 + POC 引擎”的结合体，界面中文、上手快、插件生态丰富。

核心能力：

1
2
3
4
5

MITM 抓包改包（类似 Burp 代理）
插件商店（漏洞/工具插件一键安装）
POC 执行（YAML 描述，类似 nuclei）
Web Fuzzer（手工参数测试）
端口扫描 / 漏洞扫描模块

二、影响与危害

1
2
3

Web 渗透全流程一站完成
插件/POC 批量打已知漏洞
配合手工测试效率很高

风险等级：作为工具本身无风险，滥用才危险。

三、使用 / 复现

1. MITM 抓包

1
2
3

启动 Yakit → MITM 模块
设置浏览器/系统代理指向 Yakit（默认 127.0.0.1:8787）
安装 CA 证书后即可看到并改包

可对参数做 fuzz、编码、重复请求

# 用 POC 对授权目标批量验证

四、检测（对立面）

1
2
3

Yakit MITM 有固定特征流量/证书
批量 POC 请求特征可被 WAF/态势感知识别
注意授权边界，避免触发告警

五、防御

1
2
3

WAF 拦截批量 POC 与异常探测
对漏洞插件对应的 CVE 及时补丁
做好代理与请求审计

修复

1
2
3
4

对已受影响目标：取证、清理、修复漏洞
封禁工具回连地址与端口
升级安全设备规则，补特征库
复测：异常流量与特征消失

六、小结

Yakit 的价值是“把抓包、插件、POC、扫描整合到一个平台”，特别适合国内 Web 渗透。它不能替代手工能力，但能显著提效。用它做授权测试、看清它的流量特征，攻防两端都有意义。
