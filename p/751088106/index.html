一、Wireshark 是干什么的

Wireshark 是图形化抓包与协议分析工具，能看每个包的字段、还原会话、统计流量，广泛用于排障与安全分析。

1

抓包 + 过滤 + 跟随流 + 统计，四大核心能力

六、常见坑

1
2
3

HTTPS 看不到内容 → 需解密（配 TLS key）或抓包工具代理
包太多 → 先加显示过滤再分析

影响与适用

Wireshark 用于网络排障与流量分析，是安全分析基础工具。抓包可能涉及敏感流量，仅限授权网络使用。

七、小结

Wireshark 是流量分析的基础工具：选网卡抓包 → 过滤 → 跟随流 → 统计导出。安全场景里，它和 tcpdump/tshark 配合，能还原攻击、找外联、识别隧道。抓包与分析能力，是排障和溯源都绕不开的基本功。
