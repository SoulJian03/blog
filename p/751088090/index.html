写在前面：合法学习边界

WebShell 技术只用于授权靶场。对真实系统上传 WebShell 可能触犯法律。

一、WebShell 管理工具概述

冰蝎和哥斯拉是新一代 WebShell 管理工具，相比传统的菜刀（明文传输），核心差异是加密流量 + 伪装 Content-Type，可绕过 WAF 和流量检测。

• AES-128-CBC 加密所有通信
• Base64 编码载荷

冰蝎绕过 WAF 原理

8

冰蝎发送的请求：
  Content-Type: text/xml
  Body: AES加密后的Base64字符串

WAF 看到的是：
  - 合法 Content-Type（text/xml）
  - 乱码 Body（AES 加密后的 Base64）
  → 无法识别为恶意内容

冰蝎特征：
• Content-Type: text/xml（非标准 XML 内容）
• Body 是长 Base64 字符串（无 XML 标签）
• 特定 Header 模式

哥斯拉特征：
• 随机 Header 名称和值
• Body 结构不稳定（每次不同）
• 特定参数名（如 _、%40%23 等）

检测方式：
• 流量特征分析（Content-Type 异常 + 长 Base64）
• EDR 行为检测（异常 PHP 进程 + 外联）
• WAF 行为规则（非 XML 的 text/xml 请求）
• 文件完整性监控（Web 目录新增文件告警）

七、防御

1
2
3
4
5
6

1. 文件上传限制：只允许上传图片/PDF 等安全类型
2. WAF 规则：拦截 Content-Type 异常 + 非标准编码请求
3. 文件完整性监控：Web 目录监控新增文件
4. 禁用 PHP 危险函数：system/exec/passthru/popen
5. 数据库连接最小权限：Web 应用使用专用低权限数据库账号
6. 日志审计：Web 访问日志 + PHP 错误日志

八、小结

冰蝎和哥斯拉代表了 WebShell 的"加密化"趋势。核心防御是"文件上传限制 + WAF 行为规则 + 文件完整性监控"。攻击者用加密绕过内容检测，防守者用行为分析和文件监控来发现。
